# Sources

- REBOUND: Hanno Rein and collaborators' N-body integration package.
  URL: https://rebound.readthedocs.io/

- Skyfield: Python astronomy package used here to load the JPL SPK kernel.
  URL: https://rhodesmill.org/skyfield/

- JPL DE440s ephemeris kernel, distributed as `data/de440s.bsp`.
  URL: https://ssd.jpl.nasa.gov/planets/eph_export.html

- Korycansky, Laughlin, and Adams (2001), "Astronomical engineering: a strategy for modifying planetary orbits", used as motivation for the kicked-Earth thought experiment.
  DOI: https://doi.org/10.1016/S0019-1035(01)00045-4
